# 智能客服系统 业务 PRD 对齐稿

## 目标
构建一个面向企业内部员工的智能客服系统，通过 AI 检索生成能力快速响应员工咨询，支持人工客服介入处理复杂问题，并提供知识库管理能力持续优化回答质量。

## 范围

### 包含
- 员工端：发起咨询、查看历史对话、转人工服务
- 坐席端：工单管理、人工回复、智能回答辅助、工单分类
- 知识库管理：文档上传、向量化入库、关键词索引
- 智能问答核心能力：QA 直接匹配、意图识别、记忆增强、RAG 检索生成

### 不包含
- 移动端 App
- 外部客户咨询场景（本系统仅面向企业内部员工）
- 多租户/多企业隔离（单一企业使用）
- 实时语音/视频通话

## 业务场景

### 场景 1：用户登录
- **角色**：所有用户（不区分员工/坐席）
- **入口**：登录界面
- **行为**：使用账号密码登录系统
- **边界**：
  - 登录后所有用户都可访问所有界面（员工端、坐席端、知识库管理）
  - 暂不做用户角色隔离和权限控制

### 场景 2：员工端 - 发起智能咨询
- **角色**：员工
- **入口**：员工端界面
- **行为**：员工发送问题，系统通过智能检索生成回答
- **智能回答工作链路**（关键业务逻辑）：
  1. **QA 库直接匹配**：用户 Query 向量化后检索 QA 库，计算相似度
     - 相似度 ≥ 0.8：直接返回匹配的 Answer
     - 相似度 < 0.8：进入后续流程
  2. **意图识别**：模型输出带意图判断的 JSON
     - **意图体系**：
       - 一级意图：IT问题（二级：硬件故障、硬件维修、硬件申请、软件故障、软件维修、软件申请）
       - 一级意图：权限问题（二级：软件权限、硬件权限、网络权限、其他权限）
     - **意图模糊**（is_ambiguous=true）：系统反问，要求用户提供更多细节
     - **意图清晰**：进入后续逻辑
     - **关键词回退**：如果模型无法识别，使用关键词规则进行回退判断
  3. **Query 改写**：结合长短期记忆改写用户 Query
     - **长期记忆（用户画像）**：每轮对话提取用户画像字段，存储在账号信息中（SQLite）
       - 画像字段包含：常问领域（邮件与账号、网络接入、软件使用、硬件设备）
       - 自动根据关键词归类到对应领域
     - **短期记忆**：维护轮次长度为 3 的对话窗口
     - **改写模板**：包含意图、用户画像、最近对话、当前问题
  4. **RAG 检索生成**：向量召回 + 关键词召回，RRF 混合检索，重排后生成回答
     - 如果检索不到相关知识，提示员工补充信息或转人工
- **边界**：
  - 员工可查看本轮对话历史
  - 系统自动维护长短期记忆，员工无感知
  - 意图识别和用户画像提取全部自动完成

### 场景 3：员工端 - 查看和继续历史对话
- **角色**：员工
- **入口**：员工端界面
- **行为**：选择历史工单片段，继续对话
- **边界**：
  - 已完结的工单不可继续发送消息（只读状态）
  - 未完结的工单可继续发送消息

### 场景 4：员工端 - 转人工服务
- **角色**：员工
- **入口**：员工端界面对话过程中
- **行为**：员工点击"转人工"按钮
- **目标行为**：
  - 工单状态变更为"待处理"
  - 工单进入坐席端工单池
  - 员工端显示"已转人工，等待客服处理"
- **边界**：
  - 仅提供按钮，由员工自行决定是否转人工
  - 不做自动转人工或智能建议转人工

### 场景 5：界面切换
- **角色**：所有用户
- **入口**：任意界面
- **行为**：用户可自由切换员工端、坐席端、知识库管理界面
- **边界**：所有用户都可访问所有界面，无权限限制

### 场景 6：坐席端 - 查看工单池和接单
- **角色**：坐席人员（人工客服）
- **入口**：坐席端界面
- **行为**：查看工单池（工单列表），主动选择工单进入处理状态
- **边界**：
  - 工单状态：待处理 / 处理中 / 已完结
  - 工单池展示所有"待处理"状态的工单
  - 坐席人员可查看工单的完整对话历史
  - 选择工单后，工单进入"处理中"状态
  - 坐席人员自主接单，不做自动分配

### 场景 7：坐席端 - 人工回复
- **角色**：坐席人员
- **入口**：坐席端工单详情
- **行为**：对员工问题进行人工回复
- **目标行为**：
  - 回复消息实时同步到员工端
  - 员工端可看到"人工客服"标识

### 场景 8：坐席端 - 智能回答辅助
- **角色**：坐席人员
- **入口**：坐席端工单详情
- **行为**：坐席人员可触发"智能回答"功能，系统生成建议回答
- **智能回答工作链路**：与场景 2 的"员工端智能咨询"共享相同的检索生成链路
- **回答生成规则**：
  - 使用坐席辅助 system_prompt，输出适合坐席直接发送的回复
  - 简洁、准确、分步骤可执行
  - 如果信息不足，提供排查建议模板
- **边界**：
  - 智能回答仅作为辅助建议，坐席人员可编辑后发送
  - 智能回答的工作链路与员工端一致

### 场景 9：坐席端 - 工单分类和标签
- **角色**：坐席人员
- **入口**：坐席端工单详情
- **行为**：对工单进行填单分类
- **分类映射规则**：
  - 硬件故障、硬件维修、软件故障、软件维修 → 故障类
  - 硬件申请、软件申请 → 流程类
  - 软件权限、硬件权限、网络权限、其他权限 → 权限类
  - 通用咨询 → 咨询类
- **目标行为**：
  - 分类会影响工单的元数据标签
  - 元数据用于后续数据分析和知识库优化
  - 系统可根据意图识别结果自动建议分类，坐席人员可手动调整

### 场景 10：坐席端 - 结束工单
- **角色**：坐席人员
- **入口**：坐席端工单详情
- **行为**：标记工单为"已完结"
- **目标行为**：
  - 工单进入结束状态
  - 员工端该工单变为只读，不可继续发送消息
  - 工单从坐席端"待处理"队列移除

### 场景 11：知识库管理 - 文档上传
- **角色**：知识库管理员（可能是坐席或管理员）
- **入口**：知识库界面
- **行为**：选择文件上传
- **边界**：
  - 仅支持 Markdown 格式（.md）
  - 上传后触发文档入库流程

### 场景 12：知识库管理 - 文档入库（分三个库 + QA 自动提取）
- **角色**：系统自动处理
- **触发条件**：文档上传完成
- **行为**：对文档进行处理并入库
- **关键处理逻辑**：
  1. **文档切片**：对 Markdown 文档进行分段切片
  2. **向量化入库**：切片向量化后存入向量库（SQLite）
  3. **关键词索引入库**：切片提取关键词后存入关键词检索库（SQLite）
  4. **元数据统计入库**：为切片统计元数据后存入元数据库（SQLite）
  5. **QA 自动提取**：使用模型从文档切片中自动提取 QA 对，并入 QA 库
- **边界**：
  - 三个库（向量库、关键词库、元数据库）+ QA 库均使用 SQLite 存储
  - QA 库用于 0.8 相似度阈值的直接匹配
  - 入库完成后，知识立即可被检索使用
  - QA 提取完全自动化，无需人工维护

## 验收口径

### 员工端
- 员工可登录并发起咨询，收到智能回答
- 员工可查看历史对话，已完结工单不可继续发送
- 员工可主动转人工，收到人工客服回复
- 员工可切换到知识库管理界面（权限控制）

### 坐席端
- 坐席人员可查看工单列表，选择工单进入处理
- 坐席人员可人工回复，消息实时同步到员工端
- 坐席人员可使用"智能回答"辅助功能
- 坐席人员可对工单分类和结束工单

### 知识库管理
- 管理员可上传 Markdown 文档
- 文档自动完成向量化、关键词索引、元数据统计并入库
- 入库后的知识可被智能检索使用

### 智能检索生成能力
- QA 库相似度 ≥ 0.8 时直接返回答案
- 意图模糊时系统反问
- 意图清晰时结合长短期记忆进行 RAG 检索生成
- 长期记忆维护用户画像，短期记忆维护 3 轮对话窗口

## 意图识别与用户画像体系（完整配置）

### 意图识别体系
**一级意图：IT问题**
- 二级意图：硬件故障、硬件维修、硬件申请、软件故障、软件维修、软件申请

**一级意图：权限问题**
- 二级意图：软件权限、硬件权限、网络权限、其他权限

### 判断规则
- **故障**：设备或软件本身出了问题，需要排查修复
- **维修**：需要 IT 人员上门或远程处理
- **申请**：需要新设备或新软件
- **权限**：有设备或软件但没有使用权限

### 意图识别输出格式
```json
{
  "intent_level1": "IT问题 或 权限问题",
  "intent_level2": "具体二级意图",
  "is_ambiguous": true/false,
  "clarification_question": "仅 is_ambiguous=true 时填写"
}
```

### 关键词回退规则
如果模型无法识别意图，使用关键词匹配进行回退判断：
- 硬件故障关键词：显示器不亮、黑屏、键盘没反应、鼠标失灵、没声音、开不了机、死机、屏幕闪烁、蓝屏
- 软件故障关键词：打不开、闪退、崩溃、报错、无响应、卡死
- 权限问题关键词：没有访问权限、登录不上、账号锁定、VPN、远程连接
- （完整关键词规则已记录在系统配置中）

### 用户画像提取规则
每轮对话自动提取用户常问领域，归类到以下领域：
- **邮件与账号**：Outlook、邮箱、账号、登录、OA
- **网络接入**：VPN、远程、网络、WiFi、连接
- **软件使用**：Photoshop、Office、Word、Excel、软件、安装
- **硬件设备**：显示器、键盘、鼠标、打印机、电脑、笔记本、耳机
